# English Survey Instrument

This file presents the questionnaire instrument only. It does not contain participant responses or aggregate response statistics.

## Question 1: Starting a New Assignment

Imagine you have just received a complex individual programming assignment. It is Tuesday afternoon. You sit down to start. What usually happens?

Select one option.

- **A.** I understand the task, but find it extremely hard to get started. I often procrastinate until the deadline.
- **B.** I feel "blank" or anxious because I don't see the underlying structure. I usually need a clear template or explicit steps.
- **C.** I dive in immediately, but often get stuck focusing on minor details (like code structure or variable names), losing track of the overall progress.
- **D.** I prefer to explore and experiment. I feel bored or limited if the instructions are too step-by-step or rigid.
- **E.** I usually start without any major issues.

## Question 2: The "Stuck" Moment

You are working on the code and hit a difficult bug. You have been stuck for 30 minutes. What is your immediate reaction?

Select one option.

- **A.** My focus breaks. I get restless, switch tabs, check my phone, or feel a strong urge to do something else.
- **B.** I stay focused and keep staring at the code for a long time, trying to find the logic error, but I just can't "see" it.
- **C.** I keep tweaking small things (formatting, comments, minor refactoring) to feel productive, even though I know it doesn't help.
- **D.** I feel physically overwhelmed by the environment (noise, lights, people) and need to leave the room to think clearly.

## Question 3: The Ideal Environment

Which environment allows you to be most productive?

Select one option.

- **A.** Absolute silence and controlled lighting. I find it impossible to work in a busy lab.
- **B.** A bustling environment with some background noise (e.g., a café or lab).
- **C.** It doesn't matter much to me. I can work anywhere with headphones.

## Question 4: Most Valuable Digital Assistant Functions

If you could have a digital assistant (AI or non-AI) to help you study, which functions would be most valuable? (Please select your top 3)

- **A. Task Breaker:** a tool that automatically breaks huge assignments into tiny, manageable checklists to help me start.
- **B. Pattern Hinter:** a tool that hints "This problem looks similar to [Exercise X] you did last week," to help me see the pattern.
- **C. Scope Guardian:** a tool that warns "You are spending too much time on this minor detail, move on to the next task."
- **D. Distraction Blocker:** a tool that simplifies the screen interface (hides menus/colors) so I can focus only on the task.
- **E. Concept Concrete-izer:** a tool that translates abstract textbook definitions into concrete code examples.
- **F. Structure Template:** a tool that provides the skeleton/scaffold of the code so I don't have to start from a blank page.
