# Survey instruments

This directory is reserved for the questionnaire instruments used in the thesis. It contains instruments only, not participant responses.

The survey comprises Questions 1--5:

- Questions 1--3 are scenario-based single-choice items.
- Question 4 is a candidate support feature prioritisation item.
- Question 5 is a voluntary self-identification item.

The English and Chinese survey versions were not formally validated as cross-cultural equivalents. No psychometric or cross-cultural equivalence claim is made here.

Original exported versions should be preserved when added. Readable Markdown versions may be provided alongside them without altering the questionnaire content.
